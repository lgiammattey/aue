# Autorização dos áudios (modelo a preencher)

Este arquivo é o registro de que as pessoas dos áudios do grupo "Solo Eructos!"
autorizaram o uso deles como áudio de personagem no Bonde do Arroto. Hoje ele é
só o modelo: nada abaixo foi preenchido, e a prova não existe no repositório.

O backfill do elenco da casa (`npm run elenco:backfill -- --aplicar`) lê este
arquivo e se recusa a rodar enquanto sobrar qualquer campo em aberto, marcado
com a palavra em maiúsculas que está nos campos abaixo. Quem preencher troca
cada marcador pelo dado real, sem inventar nada. Se a prova não existir, o
arquivo continua assim e a carga continua travada.

Referências: [`audios/solo-eructos/LEIAME.md`](../../../audios/solo-eructos/LEIAME.md)
e o item "Autorização dos áudios" do
[cartão de missão](cartao-de-missao-seed.md).
